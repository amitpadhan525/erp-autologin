# GIET BBS R ERP Persistent Login App - Idea & Notes

Target Website: http://gietbbsrerp.in/

## Problem Statement
The college ERP (GIET BBS R ERP) requires re-entering login credentials and a CAPTCHA every time a session expires or user reopens the app/browser.

---

## AI Vision / Deep Learning CAPTCHA Recognition (New Concept)

### How AI-Based Vision Models Recognize Text in Images:
1. **Convolutional Recurrent Neural Network (CRNN)**:
   - **Feature Extraction (CNN / ResNet)**: Converts the input image (100x40) into feature maps.
   - **Sequence Processing (BiLSTM)**: Processes feature maps sequentially left-to-right to handle overlapping characters and variable spacing.
   - **CTC Loss (Connectionist Temporal Classification)**: Decodes sequence predictions without needing character-by-character bounding box segmentation.

2. **Vision Transformers (TrOCR / ViT)**:
   - Uses an image encoder and text decoder to directly transcribe text from images end-to-end.

3. **Local AI Model Deployment Options**:
   - **PyTorch / ONNX Model**: Train a lightweight 2MB CNN+BiLSTM model in PyTorch, convert to `.onnx` or TensorFlow Lite (`.tflite`), and run directly on Android using ONNX Runtime or TFLite.
   - **Local Inference API**: Host a small FastAPI backend running the AI vision model locally on your laptop.

## Comparison: Rule-Based OCR vs. Deep Learning AI Vision

| Feature | Rule-Based / Basic OCR | AI Vision Model (CRNN / TrOCR) |
| :--- | :--- | :--- |
| **Overlapping Characters** | Fails / Splits incorrectly | Solves sequence end-to-end via CTC decoding |
| **Noise & Distortion** | High error rate | Robust to font variations and noise |
| **Accuracy** | ~70-85% | 99%+ |
| **Execution Time** | ~10-30 ms | ~15-50 ms |
